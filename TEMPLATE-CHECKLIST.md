# Template Consumption Checklist

## Identity

- [ ] Site name, origin, description, publisher, disclaimer, and owned brand assets are replaced.
- [ ] Repository, hosting project, analytics property, Search Console property, and domain are independent.

## Evidence and content

- [ ] Every public fact has an eligible source, game version, verification date, and publication state.
- [ ] Search and community signals are not presented as official facts.
- [ ] Unknown, stale, conflicting, and unsupported fields remain excluded or visibly labeled.
- [ ] Maps, coordinates, screenshots, video, and datasets have ownership or license evidence.

## Routes and SEO

- [ ] Each indexable route solves a distinct approved user task.
- [ ] Navigation, canonical, sitemap, robots, metadata, and structured data agree.
- [ ] Demonstration routes are removed or replaced; no scaffold is accidentally indexable.

## Integrations and release

- [ ] Analytics and advertising are enabled only with approved project-specific identifiers.
- [ ] Privacy and terms text match the real production behavior.
- [ ] `npm run verify` exits successfully.
- [ ] Remote source SHA, hosting deployment, custom domain, and live markers are independently verified.
